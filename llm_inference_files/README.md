LLM Inference Datasets:

Source: https://github.com/Azure/AzurePublicDataset/blob/master/AzureLLMInferenceDataset2024.md

These large datasets below are stored separately on Google Drive.

See the main project README for information about accessing the complete dataset.

    AzureLLMInferenceTrace_day1.csv – day7.csv:
        Daily 24 hour trace slices generated by decrease_dataset() from the raw multi_week Azure inference logs. A random day slice is automatically selected at runtime.
        TIMESTAMP -> arrival of prompt
        ContextTokens -> prompt input tokens evaluated during the prefill page
        GeneratedTokens -> output tokens produced during the decode stage

    llm_tokens_conv.csv
        the multi day inference trace file containing incoming LLM requests
        timestamp, context tokens, generated tokens
